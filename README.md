# Closed Loop Embedded

Source for my personal site: notes and projects on embedded Linux, signal processing, and control systems.

Published at <https://LoopOverlord1453.github.io>.

## Adding a post

Create a Markdown file in `_posts/` named `YYYY-MM-DD-title.md` with this header:

```markdown
---
layout: post
title: "Post title"
date: YYYY-MM-DD
categories: embedded-linux
---
```

Commit and push; GitHub Pages rebuilds the site automatically.
