## Hi, I'm Kubilay

I'm an engineer working on embedded systems. My interests sit where three fields meet: the
software that runs on the board, the signals that come off its sensors, and the control loops
that act on them.

Closed Loop Embedded is my public notebook. A closed loop measures its own output and corrects
itself, and that is how I try to learn: build something, measure what actually happened, write
down the error, fix it.

## What you will find here

- **Tutorials** that show the real path, including the commands that failed and the output they printed.
- **Projects** I am actively building, with an honest status on each one.
- **No copied datasheets.** If a post exists, it is because I ran the steps myself.

## What I work on

| Area | Focus |
|---|---|
| Embedded Linux | Bootloaders, kernel configuration, device trees, drivers, Buildroot and Yocto |
| Signal processing | Filter design, spectral analysis, sensor fusion, fixed-point implementation |
| Control systems | System identification, PID, state feedback, model predictive control |
| Edge AI | Quantized neural networks on microcontroller accelerators |
| FPGA and SoC | Hardware-software co-design on Zynq |

## Where I am heading

My goal is to work as a guidance, navigation, and control engineer, with embedded Linux as the
platform underneath. The projects on this site are steps in that direction: a tool for designing
estimators and controllers, a navigation system that works without satellites, and the low-level
Linux skills to put both on real hardware.

## On the bench

- **STM32N6 discovery kit** for edge AI
- **ZedBoard** (Zynq-7020) for FPGA work
